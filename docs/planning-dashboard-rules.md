# 存销看板已确认口径（2026-09-17）

## 页面与使用

- `/`：独立存销看板。按日期、仓库、物料、物料负责人、采购负责人、供应商、分类、调拨路线筛选，每页100行。
- `/data-import`：独立业务Excel输入、日期校验、质检报告及批次记录。
- `/master-data`：从顶部「基础数据」模块进入，左侧分类维护物料、供应商、仓库、调拨路线、物料管控表、仓库映射。物料管控支持手动新增/修改/停用及Excel、CSV模板导入；仓库映射保留原有手工维护和Excel导入模板。顶部「看板分析」切回业务模块，两个模块分别展示各自菜单。
- `/data-edit`：采购与调拨手工计划，以及所有已导入正式单据的历史、WMS核对、人工执行状态维护。
- `/purchase-reconciliation`：采购与WMS独立核对窗口，保留前后7天查询。

存销看板可直接输入名称/编码片段后回车查询，选中完整候选项时按精确值筛选；多个字段取交集。采购核对支持单据/关键词、供应商、仓库及物料文字部分匹配，分页保留已提交的查询条件。清空筛选保留当前日期，采购核对也保留前后天数。原有核对数量、备注保存及日期口径不变。

## 维度与数据源

一行代表一个仓库×物料。仓库取仓库基础资料；物料取物料基础资料与启用的物料管控表的并集。负责人取物料管控表。选择某人员后，保留其全部负责物料对应的全部仓库组合；其他筛选继续取交集。没有业务数量的组合显示0；负责人未维护时显示“—”。

业务导入保留原有基础资料补充规则，但不会覆盖用户手工或模板维护的物料、仓库、供应商信息。历史自动补充的基础资料仍保留。

| 字段 | 口径 |
| --- | --- |
| 库存 | 库存表库存数量汇总，不减分配或冻结；不同快照批次不累计 |
| 前三天调拨 | T-3～T-1；调出仓按出库量减，调入仓按入库量加 |
| 采购未来7天 | T+1～T+7预计到货采购数量，扣除同单号、物料、目的仓的WMS累计收货，最低为0 |
| 库存+调拨 | 库存加前三天调拨净量 |
| 库存+调拨+采购 | 上列加未来7天剩余采购 |
| 过去7天日均报货 | T-7～T-1日出库表仓库分配数量之和÷7 |
| 过去3天报货 | T-3～T-1日出库表仓库分配数量之和 |
| 今天报货 | 当日报货表下单数量 |
| 历史报货可销 | 相同窗口使用日出库表仓库拣货数量；7日列除以7 |
| 今天报货可销 | 当日报货表计划发货数量 |

历史调拨可能已经进入库存快照，库存叠加列是用户指定的算术展示，不等同于预计可用库存。WMS累计收货按已导入的记录核对；选择历史分析日期不会自动还原当时尚未导入的数据版本。

调拨出、入分别使用实际发车、实际送达日期；实际日期缺失时用对应预计日期定位实际数量，二者都缺失则不纳入三日窗口，仍保留在核对明细。已取消/关闭/作废的来源单据不纳入供给数量。

## 手工单与正式单据

手工记录生成 `MP-编号`（采购）或 `MT-编号`（调拨）临时编号，可填写“关联正式单号”。采购正式单据编号、OMS需求单号分别对应WMS参考编号3，且必须同时匹配物料与目的仓。多个WMS收货记录累计；同单同物料多行共享一个收货池，避免重复扣减。

- 有正式单号匹配：使用正式数据，手工记录只核对差异。
- 无显式单号：采购按物料、供应商、仓库、采购日期唯一匹配；调拨按物料、调出仓、调入仓、预计发车日、预计送达日唯一匹配。
- 多个候选正式单号：展示待绑定提示，该手工记录暂不额外计入，需指定单号解决重复风险。
- 尚无正式单：手工采购按预计到仓日在未来7天计入，扣除已能匹配的WMS收货；手工调拨按前三天预计发车、送达分别减/加计划安排量。
- WMS收货用于采购扣减和调拨核对，不作为另一笔采购或调拨叠加。

## 执行状态

每条手工/正式记录均有已完成、延误、未完成独立按钮。延误和未完成要求说明，所有操作要求填写修改人员并追加历史。原始系统状态与人工状态分别展示，重新导入不覆盖人工状态及说明。

手工记录标记已完成后退出临时数量；延误/未完成仍按其预计日期计入。正式单据的人工状态不代替系统数量或WMS收货证据。修改人员为本地人工填写，当前没有登录身份验证。

## 校验

大数据量下，服务端复用同日期的业务汇总、只组装当前页；数据库写入后缓存失效，翻页不重复下发未变化的筛选选项。基础资料及仓库映射同样在服务端筛选与分页，不一次性渲染全部记录。旧首页 `/#upload`、`/#mapping` 链接分别跳转数据输入及基础资料仓库映射页。

保留原有字段别名、多工作表定位、日期质检、仓库映射及风险接口。新测试覆盖10物料×全部仓库人员筛选、零业务组合、Excel/CSV物料管控、实际调拨正负及日期边界、手工正式替换、WMS分次收货/跨仓跨物料隔离、状态日志与重导保护、最新快照防累计等。

真实Excel通过 `scripts/replay_real_excel.py ... --database 独立数据库 --report 报告路径` 回放。输出只反映解析、清洗和数量变化，不构成采购或调拨业务结论。
